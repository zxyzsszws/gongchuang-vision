侧视：高度那一路

高度是独立轴，与水平伸出无关；抬高不会改变 l。
若臂是定长连杆而不是独立的直线伸出轴，抬高 Δz 后水平可达距离会变成 √(L²−Δz²)，那就不是现在这个模型了。

推导

末端 = 转轴 + (l·cos α, l·sin α)，距转轴恒为 l。
车的 x 移动只能改变「前后」，横向差额只能靠转臂：

α = asin(y / l)　← 横向
d = x − l·cos α　← 前后

|y| > l 就无解：转多少度都补不回来。
d 为正表示往前开，为负表示倒车。

本图取 +y 朝车身右侧、车身在 y<0 一侧。x 向前、y 向右、z 向上时 是左手排布；若要右手系，需把 y 定义成车身左侧（车身就落在 +y 一侧）， 两者只影响取号和三维扩展，二维公式形式不变。

# 没有场地时怎么测：合成图可视化

`tools/viz_synth.py` 把「合成图测试」变成看得见的图。测试本身只断言
「检出的靶心与真值差小于 6mm 就通过」，通过时什么都不输出，因此看不出阈值是
「刚好压线」还是「有很大余量」，也看不到误检、靶被裁掉这类只存在于画面里的问题。

## 它走哪条路径

与 `--mode live` 完全同一条代码路径，只是把相机换成了渲染出来的图：

```
场地图靶心
  --真位姿的逆--> 车身毫米
  --相机外参的逆--> 像素
  --cv2.circle--> 图像
  --detect_targets--> 像素观测
  --相机外参--> 车身毫米
  --resolve_order（含 180° 消歧）--> 位姿
```

画在图上：

- **绿圈**：检测真正找到的靶，圈上的字是识别出的圈数
- **蓝十字**：每个候选同心圆的圆心
- **红叉**：真值靶心，旁边的数字是最近的绿圈离它多远（像素）

## 用法

```powershell
# 默认参数（粗加工区、真值位姿 1500,1000,270°）
.venv\Scripts\python.exe tools\viz_synth.py

# 指定位姿与扰动
.venv\Scripts\python.exe tools\viz_synth.py --region staging --heading 92 --noise 15 --blur 1

# 六种扰动并排对比（最有用：一眼看出判据余量）
.venv\Scripts\python.exe tools\viz_synth.py --sweep

# 换分辨率/外参要改脚本顶部 SCALE，不是命令行参数
```

输出在 `logs/viz/`。

## 已经用它发现的问题

**去重阈值 `dedup_px=3.0` 在模糊时会失效。**

一条环带有内外两条轮廓，两条边界的半径差约等于画线宽度（合成图里是 2px，
去重阈值 3.0 够用）。但镜头或对焦模糊会把黑线糊宽，轮廓落在模糊带的中间位置，
两条边界半径差涨到约 4px，**超过 3.0 就不再被认成同一条环带**，于是同一圈被
计成两圈：

| 模糊半径 | 检出的圆 | 每个靶的圈数 |
|---|---|---|
| 0 | 9 | 3（正确） |
| 1 | 9 | 3（正确） |
| 2 | 15 | **4（错）** |
| 3 | 18 | **4（错）** |

圈数偏多本身不致命（`min_rings=3` 仍然满足，靶还是能认出来），但它会污染
`spread_px` 这类尺度诊断量，也会让「按圈数区分不同规格靶」的策略失效。

**处理方向**（两选一，取决于真实相机的画线宽度）：

1. 把 `dedup_px` 调到略大于「实际线宽 + 模糊宽度」，例如 6.0；
2. 或者在 `detect_circles` 里改成按「半径差 / 半径」的相对阈值去重，
   这样靶在画面里变小时不会失效。

第 2 种更稳，但要改算法；第 1 种改配置即可，代价是靶非常小的时候会把
相邻的两个真圈合并。

## 它的局限（要清楚）

- **没有镜头畸变**。`CameraCalib` 只有相似变换/单应，没有径向畸变模型。
  真实广角镜头边缘会变形，这个工具测不出来。
- **没有真实光照**。反光、阴影、纸面纹理都没有，这些恰恰是实拍最容易翻车的地方。
- **靶是纯几何画的**，没有印刷误差、没有靶心数字。

所以它是**回归测试**工具（改阈值后跑一遍确认没退化），不是**代替实拍**的工具。
真机之前，建议仍用打印的靶纸做一次实拍。
